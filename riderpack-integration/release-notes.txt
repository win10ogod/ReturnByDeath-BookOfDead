Minecraft 1.21.1 · NeoForge 21.1.248 · Java 21

騎士輪迴生存 1.3.10 的相容模組更新：riderpack-integration 1.1.4。死亡回歸與死者之書本體沿用 0.7.6。

修正 Accelerated Rendering 1.0.14 與 ImmediatelyFast 1.6.11 同時使用時，HUD 繪製的臨時光照回呼使相同物品模型每幀新增快取項目、長時間掛機持續占用記憶體的問題。只穩定模型幾何快取的識別，繪製仍使用原本的光照回呼、順序及緩衝區。

更新方式：正常退出遊戲後，將 mods/riderpack-integration-1.1.3.jar 替換為附件 riderpack-integration-1.1.4.jar，房主、朋友及專服同步替換。整合包 1.3.10 已包含此檔。本附件適用於已有騎士輪迴生存的安裝環境，依賴原包的騎士、FTB 與死亡回歸模組；完整整合包和第三方模組不包含在附件內。

原有死亡回歸、記憶畫質與歷史保留；記憶仍預設每 100 tick 保存，世界回歸點每 10 分鐘更新。保留存檔、地圖及個人設定。

驗證：
- 100,000 次等效幾何鍵測試：修正前 100,000 個快取項目，修正後 1 個；不同繪製狀態、底層 RenderType 和頂點布局仍可區分。
- 相同基地場景：修正前約 62 分鐘後有 454,946 個存活繪圖緩衝物件，修正後 30 分鐘為 22 個。兩次量測時長不同，這是指定快取累積的觀察，不能換算為整體記憶體降幅。
- 25 種物品、兩種縮放的 1080p 畫面逐像素一致。
- 雙客戶端完成 12 次世界回歸，保持原連線；不含上述兩個渲染模組的 40 模組專服啟動、停止通過。
- Java 戰鬥回歸自測 13 項通過。

實機測試使用 Linux Java 21.0.11 與隱藏顯示環境，診斷包含強制 GC。尚未完成 Windows／Radmin 整晚驗證，也不是 FPS 測試。JEI 鐵砧預覽與精妙背包仍各有舊世界引用，這輪 12 次回歸未觀察到逐次累積；本版只確認修正上述持續增長的渲染快取，未宣稱消除全部 OOM 原因。

原始碼包只含相容模組與其建構工作流。GitHub Actions 會固定依賴下載與 SHA-256，編譯、自測通過後才發布 JAR、原始碼及校驗檔。
