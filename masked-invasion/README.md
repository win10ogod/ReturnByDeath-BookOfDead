# 假面入侵 · Masked Invasion

Minecraft 1.21.1 / NeoForge 21.1.248 的據點防守附屬模組。依賴騎士工藝 1.1.4、通用變身 CF 8893780 及死亡回歸與死者之書 0.7.9；所有玩家與伺服器都需安裝。

每 3 個遊戲日，入侵者會穿著真正的騎士腰帶、盔甲和型態出現在重生點附近。遊戲日只在有生存／冒險玩家在線時累計，睡眠跳過的時間也計入。初次加入後開始計時；勝利後重新計時。

- 預告 30 秒，開戰傳回重生點。戰區預設半徑 48 格、上下各 24 格，離開會被帶回，傳送門也無法避戰。
- 首波 4 名基礎／派生型態，加 1～2 名強化型態。每位額外防守者增加 2 名；每次成功防守後增加 2 名。預設上限 32 名，可調整。
- 基礎、派生、強化型態命名為「百界士兵」；超級、最終型態命名為「百界大將」。
- 第 4 波開始出現超級型態，第 8 波開始出現最終型態。生命每波增加首波基礎的 15%，攻擊增加 10%，另保留原模組型態效果、武器與能力；Minecraft 原生屬性範圍仍適用。
- 任一防守者死亡，或 15 分鐘內未擊敗全部入侵者，判定失敗。透過死亡回歸原本的死亡記錄與世界回歸流程執行，保留現有連線。
- 多人共享世界回歸：失敗會使整個世界回到回歸點。若該據點沒有死歸持有者，會由其他在線持有者觸發回歸。開戰前必須已有回歸點且持有者在線；持有者離線後失敗則等待其回來，不把登出判作勝利。
- 共用附近重生點的玩家合併防守。全員離線時暫停入侵計時與入侵者 AI。勝利每人獲得 3 顆綠寶石，預設不掉騎士裝備。
- 入侵期間延後自動更新回歸點，避免把戰鬥存成新起點。勝利後恢復正常自動存檔；入侵狀態和進度會隨世界回歸一起還原。
- 騎士村民會將入侵者視為敵人。Mob Lassos 可以搬運村民，禁止捕捉入侵者。

## 設定

在建立／編輯世界的「遊戲規則」搜尋「假面入侵」，或使用 `/gamerule miIntervalDays 3` 等規則。警告時間、防守時限、數量、成長、技能、戰區、獎勵和裝備掉落皆可調整。`miDefenseTicks 0` 取消時限，`miEnabled false` 取消目前入侵。

`config/masked_invasion-forms.json` 為型態池，每列包含 `id`、`tier`（basic/enhanced/super/final）、`belt`、`forms`；可選 `weapon`、`weight`、`healthMultiplier`、`damageMultiplier`。只接受實際存在且相容的騎士腰帶／型態。四個階級都必須至少保留一種型態；正在入侵中使用的型態不能刪除。載入錯誤會明確報告；重新載入失敗會保留原設定。

## 指令

- `/masked_invasion status`：任何玩家查詢自己的進度。
- `/masked_invasion start [player] [wave]`：OP 2 啟動測試入侵，仍需有效回歸點與持有者。
- `/masked_invasion stop`：OP 2 取消入侵，移除入侵者並重新排程。
- `/masked_invasion reload`：OP 2 重新載入型態池。

重生點附近需要有可站立、上方兩格空間的安全位置。若沒有，入侵會等待清出空間並提示，不會拆除玩家建築。怪物只在已載入的安全位置分批生成；準備區塊採非同步等待，不在伺服器 tick 中等待網路回覆。

## 建構

使用 Java 21：

```sh
python3 scripts/import-dependencies.py --tests
./gradlew --no-daemon build runGameTestServer
```

`dependencies.lock.json` 固定依賴版本與 SHA-256；依賴 JAR 不收錄到此原始碼專案。測試模組與測試依賴不會打入正式 JAR。
